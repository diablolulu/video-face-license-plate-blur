适用于：

- Vlog

- 行车记录仪视频

对于视频中不断移动的车辆，无需手动逐帧调整马赛克位置。

## 🎯 为什么做这个工具？

平时剪辑 Vlog、自驾游、行车记录仪或者街拍视频时，经常会遇到一个问题：

**视频里面出现了大量路人和车辆牌照。**

如果使用传统视频剪辑软件，需要：

1. 找到需要打码的目标
2. 创建马赛克区域
3. 跟踪目标移动
4. 检查跟踪是否丢失
5. 对下一个目标重复操作

当一个视频里出现几十个人脸或者车牌时，处理起来非常耗时间。

这个工具希望解决的就是这个问题：

> **把重复的人脸 / 车牌打码工作尽可能交给自动识别完成。**
